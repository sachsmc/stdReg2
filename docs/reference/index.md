# Package index

## Estimation

Start with one of these for your model type.

- [`standardize()`](https://sachsmc.github.io/stdReg2/reference/standardize.md)
  : Get standardized estimates using the g-formula with a custom model
- [`standardize_coxph()`](https://sachsmc.github.io/stdReg2/reference/standardize_coxph.md)
  : Regression standardization in Cox proportional hazards models
- [`standardize_gee()`](https://sachsmc.github.io/stdReg2/reference/standardize_gee.md)
  : Regression standardization in conditional generalized estimating
  equations
- [`standardize_glm()`](https://sachsmc.github.io/stdReg2/reference/standardize_glm.md)
  : Get regression standardized estimates from a glm
- [`standardize_glm_dr()`](https://sachsmc.github.io/stdReg2/reference/standardize_glm_dr.md)
  : Get regression standardized doubly-robust estimates from a glm
- [`standardize_level()`](https://sachsmc.github.io/stdReg2/reference/standardize_level.md)
  : Get standardized estimates using the g-formula with and separate
  models for each exposure level in the data
- [`standardize_parfrailty()`](https://sachsmc.github.io/stdReg2/reference/standardize_parfrailty.md)
  : Regression standardization in shared frailty gamma-Weibull models
